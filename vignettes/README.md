# agriRank vignette map

The vignette suite is intentionally organized by analytical decision rather than by function name.

- `00-overview.Rmd` — **Design-aware nonparametric inference for agricultural experiments**
- `01-design-validation.Rmd` — **Declaring and validating agricultural experiments**
- `02-crd-oneway.Rmd` — **Completely randomized designs and one-way inference**
- `03-rcbd.Rmd` — **Randomized complete block designs**
- `04-factorial.Rmd` — **Nonparametric factorial experiments**
- `05-effects-contrasts.Rmd` — **Effect estimation, contrasts and multiple comparisons**
- `06-splitplot.Rmd` — **Split-plot, split-split-plot, strip-plot, and hierarchical randomization**
- `07-repeated-measures.Rmd` — **Rank-based repeated-measures inference**
- `08-missing-repeated.Rmd` — **Missing data in repeated-measures experiments**
- `09-trend-ancova-power.Rmd` — **Quantitative treatments, covariate adjustment and power**
- `10-multivariate-multienv.Rmd` — **Multivariate responses and multi-environment experiments**
- `11-batch-sensitivity.Rmd` — **Batch workflows and inferential sensitivity**
- `12-graphics.Rmd` — **Scientific graphics and interactive exploration**
- `13-reporting.Rmd` — **Tables, reports and reproducibility**
- `14-theory-state-of-art.Rmd` — **Statistical foundations and state of the art**
- `15-integrated-agronomic-case.Rmd` — **From experimental design to a reproducible agronomic report**
- `16-nonparametric-regression.Rmd` — **Nonparametric and shape-aware regression for agronomic gradients**
- `17-integer-support-regression.Rmd` — **Integer-support nonparametric regression for Agronomy**
