# agriRank: Design-Aware Rank-Based, Permutation and Robust Inference for Agricultural Experiments

A design-aware workflow for nonparametric, rank-based, permutation,
resampling, and robust inference in agricultural experiments.

## Details

The package treats the experimental design as a first-class object. It
integrates CRD, RCBD, factorial, split-plot, repeated-measures,
incomplete repeated-measures, multivariate, and multi-environment
workflows with effect estimates, multiplicity-aware comparisons, ggplot2
graphics, sensitivity analysis, and reproducible reports. The native
incomplete repeated-measures wild-rank engine is experimental and
rejects additional block strata rather than silently discarding them.
